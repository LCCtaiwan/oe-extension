iPHONE · OPENEVIDENCE · 兩個動作版

不拼網址，
兩個動作就能查院內藥。

從 OpenEvidence 分享藥名，跳出結果後關閉，繼續閱讀。這版改用表單直接送出文字，不需要 URL 編碼或組合網址。

新版後端需要部署一次

這份教學使用新增的 POST 功能。請先將 GitHub 分支最新的 Code.gs 與 Index.html 貼回 Apps Script，儲存後選「部署 → 管理部署作業 → 編輯 → 新版本 → 部署」。本次建置版號為 1e63f63。

只更新 GitHub 不會更新現有 GAS 網址。此教學尚未表示你的實際 GAS 部署已更新。若重新建立部署導致網址改變，步驟 2 也要改用新網址。

先確認部署能免登入使用

捷徑無法沿用 Safari 的 Google 登入。請在 Safari 私密瀏覽中開啟下面的測試連結，不登入，應看到純文字查藥結果。

測試免登入查藥 ↗
看到 Google 登入頁怎麼辦？

由管理者檢查網頁 App 的存取權限是否允許「所有人」，執行身分依部署需要設定為管理者本人。若組織政策不允許免登入，這種捷徑流程便無法使用。

依你目前選擇，本教學不設定存取碼。若部署免登入且未設存取碼，知道網址的人就能查清單；確認清單可以這樣分享再開放。此網頁不會替你變更權限。

先保留你已完成的分享設定

你截圖上已經有「從分享表單接收文字」，這個設定保留，不必重建捷徑。

  1. 若停在「選取變數」畫面，先按右上角 × 回到一般編輯畫面。
  2. 刪除先前加入的「URL 編碼」、長網址「URL」及「文字」動作。如果有 apple.com，刪除整個所屬 URL 動作即可。
  3. 分享設定保留。接下來建立的動作只會有兩個。
我還沒有建立捷徑

在「捷徑」App 點 ＋，名稱設「院內查藥」。點底部 ⓘ 或名稱旁 ⌄ → 詳細資訊，開啟「在分享表單中顯示」。回編輯畫面，點「影像和其他…」，只保留「文字」。看到「從分享表單接收文字」就完成。

動作 1A：加入「取得 URL 內容」

  1. 點畫面底部「搜尋動作」。
  2. 輸入「取得 URL 內容」，點選加入。不要選「打開 URL」。
  3. 點動作中的網址輸入欄。若它自動放入藍色「捷徑輸入」，先移除該欄的變數。
  4. 複製下方完整網址，貼到這個欄位。整串保持原樣，尾端為 /exec。

不要加 q=，也不用接藍色變數。藥名會在下面的「表單」裡傳送。

網址是固定文字，這裡不需要插入任何變數。

動作 1B：方法改成 POST

  1. 展開「取得 URL 內容」的設定。依 iOS 版本可能是動作旁的箭頭、展開按鈕或「顯示更多」。
  2. 找到目前顯示 GET 的「方法」欄位，點 GET。
  3. 從清單選 POST。
  4. 切換後，下面會出現「要求內文」（Request Body）設定。

https://script.google.com/…/exec
方法 POST ⌄
要求內文 JSON ⌄

這一步只把 GET 換成 POST。下一步再把內文改成表單。

動作 1C：要求內文選「表單」

  1. 點「要求內文」目前選項；它可能預設為 JSON。
  2. 選 「表單」（Form）。不要選 JSON 或檔案。
  3. 點「加入新的欄位」或 ＋；如果詢問欄位類型，選 「文字」。
  4. 在欄位的「鍵／名稱」填入小寫英文字母 q，只有一個字母。

動作 1D：q 的值選「捷徑輸入」

  1. 點 q 同一列右側的「值」，讓鍵盤出現。
  2. 從鍵盤上方變數列直接選 「捷徑輸入」。若沒有直接顯示，選「選取變數」，再點最上方接收分享文字所對應的藍色「捷徑輸入」。
  3. 回到編輯畫面，確認 q 右邊是藍色 〔捷徑輸入〕 膠囊。
  4. 不要手動輸入「捷徑輸入」這四個字；這裡需要真正的變數。

動作 2：加入「顯示結果」

  1. 收起鍵盤，點底部「搜尋動作」。
  2. 搜尋並加入 「顯示結果」。
  3. 來源應是剛才「取得 URL 內容」的輸出，通常顯示藍色 〔URL 的內容〕。
  4. 若來源不對，點來源欄 →「選取變數」→ 選「取得 URL 內容」動作的輸出。
  5. 按完成或返回，儲存捷徑。

在 OpenEvidence 選一個藥名試用

  1. 回到 OpenEvidence，選取藥名，例如 rosuvastatin。
  2. 點文字選單的「分享」；若沒看到，查看 › 或更多選項。
  3. 在分享選單選「院內查藥」。首次詢問連線權限時，確認為這個捷徑與 Google 回應網域後允許。
  4. 等待查藥結果出現，按「完成」關閉後繼續閱讀。

不要先在捷徑編輯器直接按播放：那時沒有分享的文字，可能只得到「請先選取或複製文字」。

卡住時，看這裡

顯示「找不到指令碼函式：doPost」

目前執行的 GAS 部署仍沒有新版 doPost。請更新完整 Code.gs 和 Index，並在管理部署作業選「新版本」部署。只按儲存或只更新 GitHub 不會生效。

顯示 Google 登入頁、HTML 或權限錯誤

先確認免登入測試能通過。捷徑不會使用 Safari 的 Google 登入狀態；在 Safari 登入本身通常不能解決。

顯示「請先選取或複製文字」

確認方法是 POST、要求內文選表單、欄位類型為文字、名稱為小寫 q，而且值是真正的藍色「捷徑輸入」變數。請從 OpenEvidence 選取藥名後分享執行。

顯示結果是網址或原始藥名

檢查第二個動作的來源。它應是「取得 URL 內容」的輸出，通常叫「URL 的內容」，不是「捷徑輸入」或固定網址。

OpenEvidence 分享選單沒有捷徑

確認已開啟在分享表單中顯示、接收文字，並且分享的是選取的藥名文字。如果 App 只允許分享整頁連結，請改用 Safari 開啟 OpenEvidence 再選字分享。

原本的 URL 編碼要留著嗎？

本版不需要。保留頂端分享設定，動作只需「取得 URL 內容」與「顯示結果」。不要把舊的編碼結果放進 q；表單會自行處理文字傳輸。

做好一次，就能分享給同事

回捷徑清單，長按「院內查藥」→「分享」→「拷貝 iCloud 連結」。同事在 iPhone 點連結，選「加入捷徑」即可。此教學頁本身不是捷徑安裝連結。

日常操作：選取藥名 → 分享 → 院內查藥 → 看結果 → 完成。

只分享藥名或不含病人識別資料的文字。
