先確認「不登入也能查」

捷徑不會沿用 Safari 的 Google 登入狀態。先用 Safari 的私密瀏覽打開測試連結，不登入 Google，確認能顯示純文字查藥結果。

如果看到 Google 登入頁，要怎麼處理？

用電腦開啟 Apps Script 專案 →「部署」→「管理部署作業」→ 編輯該網頁 App，執行身分選「我」、誰可以存取選「所有人」，再部署新版本。名稱以實際介面為準。

請使用同一部署的最新 Code.gs 與 Index。若必須建立新部署，網址會改變，步驟 4 也要換成新網址。

依本教學不設存取碼，知道網址的人就能查詢清單。若清單不可公開，或組織政策沒有「所有人」選項，請先停在這一步；這個免登入捷徑流程不適合該部署。這份 HTML 不會替你變更部署權限。

看到「院內有此藥」、「同機轉」或正常的查無結果文字，都表示 API 有回應。若是登入頁或 ⚠️ 錯誤，先處理部署，暫時不用調整捷徑。此教學未宣稱目前部署已開放免登入。

動作 2：網址後面接「變數」

搜尋並加入「URL」動作。先複製下方完整網址，貼進 URL 欄位，再把游標放到最後的 q= 後面。從鍵盤上方的變數列或「選取變數」，點選上一個「URL 編碼」動作的輸出；名稱可能是「URL 編碼的文字」。

這段只到 q= 為止。藥名由後面的藍色變數補上；不用加引號，也不要把「變數名稱」手動打進網址。

卡住時，看這裡

分享選單沒有「院內查藥」

先選取一個藥名再按分享，不要只分享整個網頁網址。滑到分享選單下方找捷徑；必要時查看「編輯動作」。回捷徑確認「在分享表單中顯示」已開啟，接收類型包含「文字」。

OpenEvidence App 沒有「選取文字 → 分享」

是否能分享選取文字，取決於原 App。如果只分享出整頁連結，請改用 Safari 開啟 OpenEvidence 再試；這個捷徑目前沒有設定「取得剪貼簿」，只拷貝文字不會自動傳入。

跳出 Google 登入頁、整段 HTML 或權限錯誤

回到最上方先測試免登入查詢。捷徑的「取得 URL 內容」沒有你的 Safari 登入狀態；重新登入 Safari 本身通常不能解決。若顯示缺少存取碼，本教學不含存取碼設定，請由管理者確認部署是否符合這個使用方式。

顯示「請先選取或複製文字」

確認「URL 編碼」輸入是「捷徑輸入」，且網址的 q= 後面接了該動作的輸出變數。請從 OpenEvidence 選取藥名後執行，不要先在捷徑編輯器直接按播放測試。

結果變成跳到 Safari

最後兩個動作應是「取得 URL 內容」和「顯示結果」。若用了「打開 URL」，就會開啟瀏覽器。

為什麼沒有「問 OpenEvidence」按鈕？

這份捷徑只查院內藥品並顯示文字。結果視窗不是能操作網頁的浮窗，也不會長駐畫面；關閉後回到原本閱讀的地方。

做好一次，同事就不用重做

回到「捷徑」清單，長按「院內查藥」→「分享」→ 找「拷貝 iCloud 連結」（可能在分享選單較下方）。若系統詢問是否上傳分享，確認後就會產生安裝連結。

把那個連結傳給同事，對方點「加入捷徑」即可。不同 iOS 版本的分享入口可能不同；這份 HTML 本身不是 iCloud 安裝連結。

完成後的日常操作：選取藥名 → 分享 → 院內查藥 → 看結果 → 完成。

只分享藥名即可，請勿輸入病人識別資料。
