院內查藥 · OE

安裝教學

選取或分享一段藥名，就能查到院內有沒有這個藥、放在哪個儲位，以及同成分、同機轉的院內品項。資料來自藥局的中央藥品資料表，停用品項不會列出。

電腦 Chrome網頁上選取文字，點「院內」約 5 分鐘 iPhone任何 App 選取文字 → 分享約 5 分鐘 Android主畫面圖示，輸入或貼上藥名約 2 分鐘

01先取得你的專屬連結

向藥局管理者索取「院內查藥」連結，格式是 https://script.google.com/macros/s/…/exec。貼在下面，本頁會產生各裝置要用的網址（只在你的瀏覽器裡計算，不會送出）。

02電腦：Chrome 擴充功能

在 OpenEvidence、UpToDate、NEJM 或本機 PDF 選取藥名，工具列會多一個「院內」按鈕。

  1. 取得擴充功能資料夾

    向管理者拿 oe-extension-v0.1.9.zip（或更新版本），解壓縮到固定位置，例如「文件」。之後不要搬動或刪除這個資料夾，Chrome 每次都從這裡載入。

  2. 打開擴充功能管理頁

    網址列輸入 chrome://extensions，右上角打開「開發人員模式」。

  3. 載入

    按「載入未封裝項目」，選剛才解壓縮出來、裡面有 manifest.json 的資料夾。

  4. 固定到工具列

    點網址列右邊的拼圖圖示，把「OpenEvidence Selection Opener」釘選。

  5. 設定院內清單

    在擴充功能圖示按右鍵 → 選項 → 「院內品項」分頁 → 「Google 試算表連結」貼上第 1 步產生的 擴充功能網址（含 api=csv）→ 按「儲存並同步」。

    • 成功會顯示品項數量，約 1500 項。
    • 之後 Chrome 啟動時與每 6 小時自動更新，不用再按。
  6. （選用）看本機 PDF

    同一頁擴充功能的「詳細資料」→ 打開「允許存取檔案網址」。

更新擴充功能：用新的 zip 覆蓋同一個資料夾，再到 chrome://extensions 按該擴充功能的重新整理鍵。設定與院內清單會保留。

03iPhone：分享選取文字查藥

在 LINE、Safari、PDF 等任何 App 選取藥名 → 分享 → 院內查藥，結果直接浮在原 App 上方。

URL 編碼輸入：捷徑輸入
URL專屬網址 + 已編碼文字
顯示網頁顯示方式輸入：URL
  1. 新增捷徑

    打開「捷徑」App → 右上角 ＋，名稱取「院內查藥」。

  2. 讓它出現在分享選單

    點下方 ⓘ（或捷徑名稱旁的選單）→ 打開「在分享表單中顯示」，接收類型只留「文字」。

  3. 動作一：URL 編碼

    搜尋「URL 編碼」加入，輸入選「捷徑輸入」，模式為「編碼」。

  4. 動作二：URL

    搜尋「URL」加入，貼上第 1 步產生的 iPhone 網址（結尾是 ?q=）。游標放在最後，點鍵盤上方的變數列，插入「已編碼文字」。

  5. 動作三：顯示網頁顯示方式

    搜尋「顯示網頁」（英文介面為 Show Web View）加入，輸入選上一步的「URL」。不要用「打開 URL」，那會跳到瀏覽器。

  6. 測試

    在備忘錄打「rosuvastatin」→ 選取 → 分享 → 院內查藥。第一次會問是否允許連線到 script.google.com，選「允許」。看到院內結果就完成了；關掉視窗會回到原 App。

別把自己做好的 .shortcut 檔傳給別人，裡面含你的專屬連結。請同仁照這頁自己建立。

04Android：加入主畫面

Android 沒有 iPhone 的捷徑檔。做法是把查藥頁加到主畫面，點開輸入或貼上藥名。

  1. 用 Chrome 開啟

    把第 1 步產生的 手機查藥頁 網址傳到手機，用 Chrome 開啟，先查一個藥確認有結果。

  2. 加到主畫面

    右上角 ⋮ →「加到主畫面」（也可能顯示「安裝應用程式」）→ 新增。

  3. 使用

    從主畫面點「院內查藥」，貼上或輸入藥名。

05查詢結果怎麼看

區塊意思
✅ 院內有此藥學名、商品名或中文名對到院內品項；下方顯示批價碼、劑型、健保價與 P1／P2／藥庫儲位。
同成分ATC 碼完全相同（7 碼）的院內品項，例如不同劑量或廠牌。
同機轉ATC 前 5 碼相同的院內品項，例如同屬 statin 類。
院內沒有院內清單找不到，會改用 NLM RxClass 查成分，仍可能列出院內的同類替代品。

電腦版的「院內」按鈕旁，還有 OpenEvidence、UpToDate、Google 等按鈕，可直接用選取文字查詢。

06疑難排解

看到的狀況處理方式
連結回傳網頁而不是清單擴充功能貼成了手機頁網址，或部署權限不是「所有人」。確認貼的是含 api=csv 的那一條；仍失敗請告知管理者。
找不到「藥名」欄位貼到的不是本服務的網址。重新複製第 1 步的擴充功能網址。
Chrome 選取後沒出現工具列該網站不在白名單：選項 → Settings → Whitelisted websites 加入網址前綴。Chrome 內建 PDF 檢視器常不出現工具列，可把文字貼到手機查藥頁，或用右鍵「Ask OpenEvidence」。
iPhone 捷徑跳到瀏覽器最後一個動作用了「打開 URL」，改成「顯示網頁顯示方式」。
iPhone 結果一片空白檢查 URL 動作結尾的「已編碼文字」是變數（藍色膠囊），不是手打的字。
剛停用或新增的藥沒更新手機頁最多約 10 分鐘更新；擴充功能到選項按「儲存並同步」立即更新。
