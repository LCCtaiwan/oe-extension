    院內清單

    最簡單：不用設定

    1. Safari 打開本頁 → 下方「分享」→「加入主畫面」。
    2. 之後在任何 App 複製藥名 → 點主畫面的「院內查藥」→ 長按輸入框選「貼上」，會自動查詢。

    從分享選單開啟（2 個動作的捷徑）

    1. 「捷徑」App → ＋ → 命名「院內查藥」→ 點 ⓘ 開啟「在分享表單中顯示」。
    2. 加入「URL 編碼」（輸入是「捷徑輸入」）。
    3. 加入「打開 URL」，貼上這串，最後接上變數「已 URL 編碼的文字」：

    之後選取文字 → 分享 →「院內查藥」，本頁會帶著文字打開並查好。做好後長按捷徑 → 分享 →「拷貝 iCloud 連結」傳給同事，他們點一下就裝好，不用自己做。

    進階：結果直接跳在原本的 App 上
    1. 同上建立捷徑，「如果沒有輸入」選「取得剪貼簿」，加入「URL 編碼」。
    2. 加入「取得 URL 內容」，網址貼上這串並接上「已 URL 編碼的文字」：
    3. 加入「從選單中選擇」，提示選「URL 的內容」，選項：「問 OpenEvidence」「查健保給付」「PICO 後問 OE」「完成」。
    4. 「問 OpenEvidence」底下「打開 URL」： https://www.openevidence.com/ask?configName=prod&attachments=%5B%5D&query= 接上「已 URL 編碼的文字」。
    5. 「查健保給付」底下「打開 URL」： 接上「已 URL 編碼的文字」。
    6. 「PICO 後問 OE」（需設定 Groq）：「取得 URL 內容」 接上「已 URL 編碼的文字」→「URL 編碼」它的結果 →「打開 URL」OpenEvidence 網址接上這個新結果。
    7. 可再設「背面輕點」：設定 → 輔助使用 → 觸控 → 背面輕點 → 點兩下 →「院內查藥」。
