    院內清單

    不用切換 App：iPhone 捷徑

    在 OpenEvidence、PDF 或任何 App 選取文字 → 分享 →「院內查藥」，結果直接跳在原本的畫面上，同一個選單一鍵問 OpenEvidence。也可以設成「背面輕點」：複製文字後敲手機背面兩下。

    建立捷徑（約 3 分鐘，做一次）
    1. 「捷徑」App → ＋ → 命名「院內查藥」→ 點 ⓘ 開啟「在分享表單中顯示」，類型勾「文字」；「如果沒有輸入」選「取得剪貼簿」。
    2. 加入「URL 編碼」，輸入選「捷徑輸入」。
    3. 加入「取得 URL 內容」，網址貼上這串，最後接上變數「URL 編碼的文字」：
    4. 加入「從選單中選擇」，提示選變數「URL 的內容」，選項：「問 OpenEvidence」「PICO 後問 OE」「完成」。
    5. 「問 OpenEvidence」底下加「打開 URL」： https://www.openevidence.com/ask?configName=prod&attachments=%5B%5D&query= 接上「URL 編碼的文字」。
    6. 「PICO 後問 OE」（需設定 Groq）：先「取得 URL 內容」 接上「URL 編碼的文字」，再「URL 編碼」它的結果，最後「打開 URL」同上一步的 OpenEvidence 網址接上這個新結果。
    7. 做好後長按捷徑 → 分享 →「拷貝 iCloud 連結」，傳給同事就能直接加入。
    背面輕點（複製後敲兩下）

    設定 → 輔助使用 → 觸控 → 背面輕點 → 點兩下 → 選「院內查藥」。之後複製文字、敲手機背面兩下就會查詢剪貼簿的內容。
